
# Melanoma Skin Cancer Classification using CNN

## Project Overview
This project uses a Convolutional Neural Network (CNN)
to classify skin lesion images into Benign and Malignant
categories.

## Technologies
- Python
- TensorFlow
- Keras
- Streamlit
- NumPy
- Pillow

## Features
- Upload skin images
- CNN-based image classification
- Display predicted class
- Display model confidence

## Disclaimer
This project is for educational purposes only and
must not be used as a substitute for professional
medical diagnosis.
